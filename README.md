# eac — KPR Concept Recreation

A cyberpunk-style interactive story experience concept recreation.

## Features

- Preloader with file loading simulation
- Scramble text decode effects
- Rotating hero words (KEEP / PROTECT / REIMAGINE)
- Themed sections (dark / light / lavender)
- Fullscreen menu + interactive console
- Canvas background (grid, particles, scanlines, glitches)
- Collection count-up & live counter
- Audio hum toggle (Web Audio API)
- Responsive layout

## Structure

```
.

│   └── style.css

```

## Local preview

Just open `index.html` in a browser (or use any static server).

```bash
npx serve .
```
